# NaturalTag process video generator

Rebuilds `src/assets/video/NaturalTag Process.mp4` deterministically. The scene
is an SVG driven by a `setTime(t)` clock, rendered frame by frame in headless
Chromium and encoded with ffmpeg. Nothing is generated by an AI model, which is
the point: labels are text nodes, and the leaf and cloud marks are the actual
PNG files from `src/assets/logos/`, embedded byte for byte.

Do not replace this video with output from a generative video model. The
original was made that way and shipped with misspelled labels, stray hex codes
rendered as text, and a redrawn logo. The archived copy in `legacy/` at the
repository root documents those failure modes.

## Requirements

Node 20+, ffmpeg on PATH, and the repository's own `node_modules` (the scripts
use the repo's Playwright and Montserrat packages). Run everything from this
directory.

## Rebuild

```
mkdir -p out/frames
node build.mjs        # writes out/scene.html with all assets inlined
node render.mjs       # renders 300 frames at 1920x1080 into out/frames/
ffmpeg -framerate 30 -i out/frames/%04d.png -c:v libx264 -profile:v high \
  -pix_fmt yuv420p -crf 21 -preset slow -movflags +faststart \
  "../../src/assets/video/NaturalTag Process.mp4"
node audit.mjs        # verify before committing (see below)
```

## Verify before committing

`audit.mjs` checks, from the DOM rather than by eye: the seven stop names are
spelled exactly as the site spells them, there are exactly seven discs, the
tagline is exactly "Tag. Trace. Trust.", both logo images are byte-identical
to the files in `src/assets/logos/`, and no two connector lines pass within
8px of each other. It prints PASS/FAIL per check. Do not commit a render that
fails any of them.

The video is a seamless loop: frame 299 and frame 0 are pixel-identical
because every animation is periodic over the 10-second duration and the truck
is off-canvas at both ends. If you change any timing, keep every cycle length
a divisor of the total duration or the loop will visibly jump.

## Changing things

Everything is parametric in `build.mjs`: the road path, stop count and
wording (`NODES`), colours (taken from the brand palette), timing constants in
the `setTime` clock, and the tagline. Change the data, re-render, re-audit.

Two rules learned the hard way:

- Never put a hex colour code in any generative prompt connected to this
  video. Models render colour codes as on-screen text.
- The stop names must match `src/_data/home.yml` word for word. The audit
  enforces this; if the site copy changes, change `NODES` to match.
